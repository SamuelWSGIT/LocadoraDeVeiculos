# Regras do projeto

- Utilize React, TypeScript e Vite.
- Responda sempre em português brasileiro.
- Utilize componentes reutilizáveis.
- Priorize mobile first e responsividade.
- Preserve as funcionalidades existentes.
- Utilize código limpo e acessível.
- Não instale dependências desnecessárias.
- Execute o build e o lint após alterações.
- Explique as alterações realizadas.
- Não faça commits ou push sem autorização.
- Não exponha senhas ou chaves de API.
